> **Note:** Large datasets and files have been removed from this repository to ensure smooth pushing to GitHub. Exercises and examples use smaller, representative datasets.

## 📚 Repository Overview

The repository is divided into **phases** that represent my progression:

### Phase 1: Python & Jupyter Basics
`Phase_1_Jupyter_Python_Basics/`

- Python fundamentals: variables, operators, loops, and conditionals
- Functions, modules, and OOP basics
- Jupyter Notebook environment mastery
- Small exercises and mini-projects for practical application
- Solid foundation for advanced Data Science tasks

### Phase 2: Data Cleaning & Analysis
`Phase_2_Data_Cleaning_and_Analysis/`

Focuses on **data preparation and analysis**, the core of Data Science.

#### 01_numpy
- Multidimensional arrays, indexing, slicing
- Broadcasting, vectorized operations
- Efficient numerical computation for data processing

#### 02_pandas
- DataFrames and Series manipulation
- Indexing, filtering, grouping, aggregation
- Handling missing values and duplicates
- **LeetCode Pandas problem solutions** to strengthen applied skills

#### 03_data_cleaning
- Advanced data wrangling techniques
- Data normalization and transformation
- Preparing datasets for analysis or modeling
